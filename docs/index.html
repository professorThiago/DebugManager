DebugManager

Log em 6 níveis para Arduino e ESP32, com saídas extras (arquivo, MQTT, display...), gravação no LittleFS e API em português e inglês.

6-level logging for Arduino and ESP32, with extra outputs (file, MQTT, display...), LittleFS file logging and a Portuguese and English API.

version 3.1.0 license MIT platforms * API PT + EN

Uso básicoBasic usage

cpp
configurarDebug(DEBUG_INFO);          // nível do Serial
configurarDebug(DEBUG_INFO, 4);       // GPIO 4 no GND ao ligar força DEBUG_TUDO
configurarDebug(DEBUG_INFO, -1, 0);   // 0 = não chama Serial.begin() (seu código já chamou)

debugErro("Sensor nao respondeu");                  // texto fixo: não cria String
debugAviso("Fila em " + String(fila) + "/30");      // String
debugInfof("RSSI: %d dBm | heap: %u", rssi, heap);  // estilo printf

definirNivelDebug(DEBUG_VERBOSE);     // muda em tempo de execução
mostrarTempoDebug(true);              // [   12.345] [INFO]    ...
definirPortaDebug(Serial1);           // outra porta serial

// Só monta o texto caro se alguém for receber
if (debugHabilitado(DEBUG_TUDO)) debugTudo("Payload: " + payloadGigante);
cpp
configureDebug(DEBUG_INFO);           // Serial level
configureDebug(DEBUG_INFO, 4);        // GPIO 4 tied to GND at boot forces DEBUG_TRACE
configureDebug(DEBUG_INFO, -1, 0);    // 0 = do not call Serial.begin() (your code did)

debugError("Sensor not responding");                // fixed text: no String created
debugWarning("Queue at " + String(queue) + "/30");  // String
debugInfof("RSSI: %d dBm | heap: %u", rssi, heap);  // printf style

setDebugLevel(DEBUG_VERBOSE);         // change at runtime
showDebugTime(true);                  // [   12.345] [INFO]    ...
setDebugPort(Serial1);                // another serial port

// Only build the expensive text if someone will receive it
if (isDebugEnabled(DEBUG_TRACE)) debugTrace("Payload: " + hugePayload);

Saídas extrasExtra outputs

Uma saída extra é uma função que recebe as mensagens para fazer o que você quiser: gravar em arquivo, publicar por MQTT, mostrar num display, acender um LED. Cada saída tem o seu nível, independente do Serial — dá para deixar o Serial silencioso e gravar avisos em arquivo, ou ver tudo no Serial e gravar só erros.

An extra output is a function that receives messages to do whatever you want: write to a file, publish over MQTT, show on a display, light an LED. Each output has its own level, independent from Serial — keep Serial silent while saving warnings to a file, or see everything on Serial while saving only errors.

cpp
int id = adicionarSaidaDebug([](int nivel, const char* msg) {
    display.println(msg);                 // recebe cada mensagem com nível <= DEBUG_AVISO
}, DEBUG_AVISO);

definirNivelSaidaDebug(id, DEBUG_ERRO);   // muda o nível dessa saída
removerSaidaDebug(id);                    // remove
cpp
int id = addDebugOutput([](int level, const char* msg) {
    display.println(msg);                 // receives every message with level <= DEBUG_WARNING
}, DEBUG_WARNING);

setDebugOutputLevel(id, DEBUG_ERROR);     // change this output's level
removeDebugOutput(id);                    // remove it
  • Até 4 saídas ao mesmo tempo (-DDEBUG_MANAGER_MAX_SAIDAS=8 para mais). adicionarSaidaDebug devolve -1 se não houver espaço.
  • Uma mensagem gerada dentro de uma saída extra vai só para o Serial, para não entrar em loop.
  • ESP32, ESP8266 e RP2040 aceitam lambdas com captura; no AVR use funções comuns ou lambdas sem captura.
  • Up to 4 outputs at once (-DDEBUG_MANAGER_MAX_SAIDAS=8 for more). addDebugOutput returns -1 when full.
  • A message produced inside an extra output only goes to Serial, to avoid infinite loops.
  • ESP32, ESP8266 and RP2040 accept capturing lambdas; on AVR use plain functions or non-capturing lambdas.

Log no LittleFS (ESP32)Log to LittleFS (ESP32)

DebugLittleFS é uma saída extra pronta que grava em arquivo. Tudo o que passa pelo DebugManager vai para /logs/atual.log, com data e hora.

DebugLittleFS is a ready-made extra output that writes to a file. Everything that goes through DebugManager ends up in /logs/atual.log, with date and time.

cpp
#include <DebugManager.h>
#include <DebugLittleFS.h>

void setup() {
    configurarDebug(DEBUG_INFO);

    DebugLittleFS::Config cfg;
    cfg.nivel             = DEBUG_AVISO;   // o que vai para o arquivo
    cfg.tamanhoMaxArquivo = 64 * 1024;     // gira a cada 64 KB
    cfg.arquivosAntigos   = 2;             // atual.log + 1.log + 2.log
    debugLittleFS.iniciar(cfg);
}

void loop() {
    debugLittleFS.atualizar();             // grava o buffer e traz os erros do ESP-IDF
}

// Quando o WiFi conectar: data e hora reais (padrão: horário de Brasília)
debugLittleFS.sincronizarHorario();
cpp
#include <DebugManager.h>
#include <DebugLittleFS.h>

void setup() {
    configureDebug(DEBUG_INFO);

    DebugLittleFS::Config cfg;
    cfg.nivel             = DEBUG_WARNING; // what goes to the file
    cfg.tamanhoMaxArquivo = 64 * 1024;     // rotate every 64 KB
    cfg.arquivosAntigos   = 2;             // atual.log + 1.log + 2.log
    debugLittleFS.begin(cfg);
}

void loop() {
    debugLittleFS.update();                // flushes the buffer and pulls ESP-IDF errors
}

// When WiFi connects: real date and time (default: Brasília time zone)
debugLittleFS.syncTime();                  // or syncTime("UTC0") etc.

Cuidados com a flash

• Linhas comuns ficam num buffer em RAM e vão para a flash a cada 30 s. Erros e avisos são gravados na hora — se o ESP32 travar, eles já estão salvos.

• O LittleFS não é formatado automaticamente, porque pode guardar certificados e páginas.

• O Upload Filesystem Image substitui o LittleFS inteiro, inclusive a pasta /logs.

• Chame gravarAgora() antes de ESP.restart() ou deep sleep.

Flash wear

• Regular lines stay in a RAM buffer and are flushed every 30 s. Errors and warnings are written immediately — if the ESP32 crashes, they are already saved.

• LittleFS is never formatted automatically, since it may hold certificates and pages.

• Upload Filesystem Image replaces the whole LittleFS, including /logs.

• Call flush() before ESP.restart() or deep sleep.

Com a ConectividadeESP32With ConectividadeESP32

A ConectividadeESP32 escreve suas mensagens pelo DebugManager. Ligando o DebugLittleFS, os códigos de erro do WiFi, do MQTT e da AWS vão direto para o arquivo — dá para investigar uma queda que aconteceu de madrugada.

ConectividadeESP32 writes its messages through DebugManager. With DebugLittleFS enabled, WiFi, MQTT and AWS error codes go straight to the file — you can investigate a disconnection that happened overnight.

cpp
#include <ConectividadeESP32.h>
#include <DebugLittleFS.h>

void setup() {
    configurarDebug(DEBUG_INFO);
    debugLittleFS.iniciar(DEBUG_AVISO);

    conectividade.registrarCallbackWiFiConectado([]() {
        debugLittleFS.sincronizarHorario();       // log com data e hora
    });
    conectividade.beginAWS(WIFI_SALVO, aws, topicos);
}

void loop() {
    conectividade.update();
    debugLittleFS.atualizar();
}
cpp
#include <ConectividadeESP32.h>
#include <DebugLittleFS.h>

void setup() {
    configureDebug(DEBUG_INFO);
    debugLittleFS.begin(DEBUG_WARNING);

    connectivity.onWiFiConnected([]() {
        debugLittleFS.syncTime();                 // timestamps in the log
    });
    connectivity.beginAWS(SAVED_WIFI, aws, topics);
}

void loop() {
    connectivity.update();
    debugLittleFS.update();
}

Histórico de versõesChangelog

3.1.0

  • Saídas extras com nível próprio.
  • DebugLittleFS (ESP32): log em arquivo com rotação, buffer em RAM, NTP, motivo do reset e captura dos erros do ESP-IDF.
  • Funções estilo printf e versões const char* que não criam String.
  • debugHabilitado(), definirPortaDebug(), mostrarTempoDebug(), nomeNivelDebug(), debugLog().
  • configurarDebug() aceita a velocidade do Serial e espera o USB nativo (ESP32-S3) por até 1,5 s.
  • DEBUG_NENHUM não imprime mais o cabeçalho. Mutex no ESP32.
  • API em inglês. Totalmente compatível com a 3.0.0.
  • Extra outputs with their own level.
  • DebugLittleFS (ESP32): rotating file log, RAM buffer, NTP, reset reason and ESP-IDF error capture.
  • printf-style functions and const char* overloads that create no String.
  • isDebugEnabled(), setDebugPort(), showDebugTime(), debugLevelName(), debugLog().
  • configureDebug() takes the Serial baud rate and waits up to 1.5 s for native USB (ESP32-S3).
  • DEBUG_NONE no longer prints the banner. Mutex on ESP32.
  • English API. Fully compatible with 3.0.0.
